# FPGA pinout data

`FPGA-SC-02034-3-0-ECP5U-45-Pinout.csv` is Lattice's official pinout for the ECP5 LFE5U-45
(document FPGA-SC-02034, revision 3.0, 17 Sep 2021), kept here unmodified as the single source for
the caBGA554 ball functions (the 554 balls of the `CABGA554` column are all distinct; its 245 GPIO
balls match the nextpnr/prjtrellis IO database).
Copyright Lattice Semiconductor; check their terms before redistributing outside this repo.
Used by `hardware/` generators for the FPGA symbol, footprint and pin assignment.
